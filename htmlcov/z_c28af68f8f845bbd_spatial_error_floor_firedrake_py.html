8def coarse_space_error(u, coarse_space, buffers): 

9 r""" 

10 The part of `u` that a coarser space cannot represent, :math:`\|u - P R u\|_{L^2}`. 

11 

12 Here :math:`R` is the :math:`L^2` projection onto `coarse_space` and :math:`P` the prolongation back. For a smooth 

13 solution, this is about the error of the coarse space, so dividing it by :math:`2^{p+1}` estimates the 

14 :math:`L^2` error of a degree :math:`p` space on a mesh refined once. 

15 

16 Args: 

17 u (firedrake.Function): Function on a mesh of a Firedrake ``MeshHierarchy`` 

18 coarse_space (firedrake.FunctionSpace): Space on the next coarser mesh of the same hierarchy 

19 buffers (dict): Transfer buffers, kept by the caller, see 

20 :func:`~pySDC.implementations.transfer_classes.TransferFiredrakeMesh.run_transfer` 

21 

22 Returns: 

23 float: :math:`\|u - P R u\|_{L^2}` 

24 """ 

25 coarse_load = run_transfer( 

26 'restrict', riesz_map(u.function_space())(u), fd.Cofunction(coarse_space.dual()), buffers 

27 ) 

28 back = run_transfer('prolong', riesz_map(coarse_space)(coarse_load), fd.Function(u.function_space()), buffers) 

29 return fd.norm(u - back)

32class SpatialErrorFloorFiredrake(ConvergenceController): 

33 r""" 

34 Stop iterating once the residual is small compared with the spatial discretization error, for Firedrake problems. 

35 

36 Iterating further cannot make the solution more accurate than its spatial error allows. This controller estimates 

37 that error at the end of the step, :math:`e_x = \|u - P R u\| / 2^{p+1}` (see :func:`coarse_space_error`), once 

38 per step after its first iteration, and declares the step converged once (on the last collocation node, the end 

39 point for RADAU-RIGHT) 

40 

41 .. math:: 

42 \|r\| \le \gamma \, e_x \, \Delta t / T, 

43 

44 in addition to the usual criteria such as ``restol``, which remains the floor where the spatial error is small. 

45 The factor :math:`\Delta t / T` turns the global spatial error into a budget per step, since what each step leaves 

46 of the iteration error adds up over the :math:`T / \Delta t` steps. 

47 

48 The residual :math:`r` has to be measured in the :math:`L^2` norm for this comparison: for the mass-matrix 

49 sweepers it is a load vector, whose norm (:class:`~pySDC.implementations.datatype_classes.firedrake_mesh.firedrake_dual_mesh`) 

50 is that of the function it represents. For diffusive problems, it bounds the iteration error up to a modest 

51 constant, which is why :math:`\gamma = 1` is a safe default. 

52 

53 The estimate assumes a smooth solution, so that the error of a degree :math:`p` space falls by :math:`2^{p+1}` when 

54 the mesh is refined once. It needs a coarse space on the next coarser mesh of a ``MeshHierarchy`` and an absolute 

55 residual (``residual_type`` ``'full_abs'`` or ``'last_abs'``), since a relative one is not comparable with the error. 

56 

57 It works with PFASST, too, because it only adds to the convergence decision of its own step: each step keeps its 

58 own estimate, from its own end point, and is declared done right after 

59 :class:`~pySDC.core.check_convergence.CheckConvergence` decided on the usual criteria (hence the control order 

60 above 200). Sharing the decision across the block is then left to ``CheckConvergence.communicate_convergence``, so 

61 a step still finishes only once the one before it has. Setting ``force_done`` instead would not do: the MPI 

62 controller reads it as "abort the block" and skips the communication, and with ``all_to_done`` it is shared by 

63 all steps. 

64 

65 Parameters: 

66 coarse_space (firedrake.FunctionSpace): Space of the same kind on the next coarser mesh of the hierarchy 

67 Tend (float): End time of the run 

68 gamma (float, optional): Safety factor, 1 by default 

69 """

116 def check_iteration_status(self, controller, S, **kwargs): 

117 """ 

118 Declare the step converged if its residual on the finest level is within its spatial error budget. 

119 

120 Args: 

121 controller (pySDC.Controller): The controller 

122 S (pySDC.Step): The current step 

123 

124 Returns: 

125 None 

126 """ 

127 L = S.levels[0] 

128 # the spatial error hardly changes while the step iterates, so it is estimated from the initial guess and once 

129 # more after the first iteration only: on the FEM study that left every iteration count unchanged and cut the 

130 # time spent here 3-10 times 

131 if S.status.iter <= 1: 

132 u = L.u[-1].functionspace 

133 degree = u.function_space().ufl_element().embedded_superdegree 

134 S.status.spatial_error = coarse_space_error(u, self.params.coarse_space, self.buffers) / 2 ** (degree + 1) 

135 if L.status.residual <= self.params.gamma * S.status.spatial_error * L.dt / self.params.Tend: 

136 self.debug( 

137 f'Residual {L.status.residual:.2e} below the spatial error budget of {S.status.spatial_error:.2e}', S 

138 ) 

139 S.status.done = True
