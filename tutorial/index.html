Tutorials#

To flatten the steep learning curve of SDC and the likes, this tutorial contains nine steps to introduce, demonstrate and briefly discuss the main features of pySDC. We start with a simple problem setup, add the collocation problem, solve this via SDC, MLSDC and finally PFASST and discuss further extensions. Along the way we highlight special features of pySDC and explain how different features or implementations can be used (or disabled).

All tutorials are supported by tests, which the continuous integration runs for every pull request and every push to master. The website runs the parts again when it is built and shows their output; for the few parts that need MPI, FEniCS, a GPU and the like, it shows the output of the tests instead.
