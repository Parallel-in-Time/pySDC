implementations.convergence_controller_classes.adaptive_alpha module¶

class AdaptiveAlpha(controller: Controller, params: Dict[str, Any], description: Dict[str, Any], **kwargs: Any)[source]¶

Bases: ConvergenceController

Choose the ParaDiag \(\alpha\) adaptively from the residual.

ParaDiag replaces the time-stepping matrix by an \(\alpha\)-circulant approximation, and \(\alpha\) trades two error sources against each other: a small value approximates the original problem better, but conditions the diagonalization worse, so round-off and inexact inner solves contaminate the result. A single fixed \(\alpha\) therefore has to be a compromise for the whole run, even though the balance shifts as the residual falls.

This convergence controller updates \(\alpha\) after every iteration instead, following the strategy in Čaklović et al.:

\[\gamma = L (3 \epsilon + \tau), \quad \alpha_{k} = \sqrt{\frac{\gamma r_k}{e_k}}, \quad e_{k+1} = 2 \sqrt{\gamma e_k r_k},\]

with \(L\) the number of steps in the block, \(\epsilon\) machine precision, \(\tau\) the inner solver tolerance, \(r_k\) the residual and \(e_k\) a running bound on the error. \(\gamma\) is the accuracy floor: there is no point pushing \(\alpha\) below the level at which round-off and the inner solver dominate anyway.

The residual is reduced over the whole block, so every rank computes the same \(\alpha\) and the controllers stay in step.
