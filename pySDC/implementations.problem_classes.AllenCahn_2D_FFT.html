implementations.problem_classes.AllenCahn_2D_FFT module¶

class allencahn2d_imex(nvars=None, nu=2, eps=0.04, radius=0.25, L=1.0, init_type='circle', useGPU=False)[source]¶

Bases: Problem

Example implementing the two-dimensional Allen-Cahn equation with periodic boundary conditions, with the two phases at \(u = 0\) and \(u = 1\)

\[\frac{\partial u}{\partial t} = \Delta u + \frac{1}{2\varepsilon^2} (2u - 1)\left(1 - (2u - 1)^\nu\right)\]

for a constant \(\nu\), which at the default \(\nu = 2\) is the usual \(\Delta u - \frac{2}{\varepsilon^2} u (1 - u)(1 - 2u)\).

On a spatial domain \([-\frac{L}{2}, \frac{L}{2}]^2\). Different initial conditions can be used, for example, circles of the form

\[u({\bf x}, 0) = \frac{1}{2}\left(1 + \tanh\left(\frac{r - \sqrt{x_i^2 + y_j^2}} {\sqrt{2}\varepsilon}\right)\right),\]

or checker-board

\[u({\bf x}, 0) = \frac{1}{2}\left(1 + \sin(2 \pi x_i) \sin(2 \pi y_j)\right),\]

or uniform distributed random numbers in \([0, 1]\) for \(i, j=0,..,N-1\), where \(N\) is the number of spatial grid points. For time-stepping, the problem is treated semi-implicitly, i.e., the diffusion part is solved by Fast-Fourier Transform (FFT) and the nonlinear term is treated explicitly.

An exact solution is not known, but instead the numerical solution can be compared via a generated reference solution computed by a SciPy routine.

Parameters:

  • nvars (List of int tuples, optional) – Number of unknowns in the problem, e.g. nvars=[(128, 128), (128, 128)].

  • nu (int, optional) – Exponent of the double well; \(\nu = 2\) is the standard Allen-Cahn nonlinearity.

  • eps (float, optional) – Scaling parameter \(\varepsilon\).

  • radius (float, optional) – Radius of the circles.

  • L (float, optional) – Denotes the period of the function to be approximated for the Fourier transform.

  • init_type (str, optional) – Indicates which type of initial condition is used.

  • useGPU (bool, optional) – Run on the GPU with CuPy instead of on the CPU with NumPy.

reaction(u)[source]¶

The reaction term, \(\frac{1}{2\varepsilon^2}(2u - 1)\left(1 - (2u - 1)^\nu\right)\).

The wells sit at \(u = 0\) and \(u = 1\), so the double well is symmetric about \(2u - 1\); writing the term in that variable is what lets \(\nu\) keep the meaning it has always had here. For the default \(\nu = 2\) this is \(-\frac{2}{\varepsilon^2} u (1 - u)(1 - 2u)\).

class allencahn2d_imex_stab(nvars=None, nu=2, eps=0.04, radius=0.25, L=1.0, init_type='circle', useGPU=False)[source]¶

Bases: allencahn2d_imex

This implements the two-dimensional Allen-Cahn equation with periodic boundary conditions, with the two phases at \(u = 0\) and \(u = 1\)

\[\frac{\partial u}{\partial t} = \Delta u + \frac{1}{2\varepsilon^2} (2u - 1)\left(1 - (2u - 1)^\nu\right)\]

for a constant \(\nu\), which at the default \(\nu = 2\) is the usual \(\Delta u - \frac{2}{\varepsilon^2} u (1 - u)(1 - 2u)\).

On a spatial domain \([-\frac{L}{2}, \frac{L}{2}]^2\). Different initial conditions can be used here, for example, circles of the form

\[u({\bf x}, 0) = \frac{1}{2}\left(1 + \tanh\left(\frac{r - \sqrt{x_i^2 + y_j^2}} {\sqrt{2}\varepsilon}\right)\right),\]

or checker-board

\[u({\bf x}, 0) = \frac{1}{2}\left(1 + \sin(2 \pi x_i) \sin(2 \pi y_j)\right),\]

or uniform distributed random numbers in \([0, 1]\) for \(i, j=0,..,N-1\), where \(N\) is the number of spatial grid points. For time-stepping, the problem is treated semi-implicitly, i.e., the diffusion part is solved with Fast-Fourier Transform (FFT) and the nonlinear term is treated explicitly.

An exact solution is not known, but instead the numerical solution can be compared via a generated reference solution computed by a SciPy routine.

Same equation as allencahn2d_imex, split differently: \(-\frac{2}{\varepsilon^2}\) is folded into the implicit operator and \(\frac{2}{\varepsilon^2}u\) added back to the explicit part, which leaves the sum unchanged but flattens the explicit part at both wells, since the reaction has derivative \(-\frac{2}{\varepsilon^2}\) at each of them.

Parameters:

  • nvars (List of int tuples, optional) – Number of unknowns in the problem, e.g. nvars=[(128, 128), (128, 128)].

  • nu (int, optional) – Exponent of the double well; \(\nu = 2\) is the standard Allen-Cahn nonlinearity.

  • eps (float, optional) – Scaling parameter \(\varepsilon\).

  • radius (float, optional) – Radius of the circles.

  • L (float, optional) – Denotes the period of the function to be approximated for the Fourier transform.

  • init_type (str, optional) – Indicates which type of initial condition is used.

  • useGPU (bool, optional) – Run on the GPU with CuPy instead of on the CPU with NumPy.
