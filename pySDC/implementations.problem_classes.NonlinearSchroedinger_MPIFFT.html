class nonlinearschroedinger_fully_implicit(lintol=1e-09, liniter=99, **kwargs)[source]¶

Bases: nonlinearschroedinger_imex

Periodic nonlinear Schrödinger equation with mpi4py-fft, fully implicit with SciPy’s Newton-Krylov solver.

Example implementing the \(N\)-dimensional nonlinear Schrödinger equation with periodic boundary conditions

\[\frac{\partial u}{\partial t} = i \Delta u + 2 N c i |u|^2 u\]

for fixed parameter \(c \in \{0, 1\}\) and \(N=2, 3\), on \([0, 2\pi]^N\). The factor \(N\) makes the one-dimensional breather solution (39) of https://doi.org/10.1007/BF01017105, taken along \(x_1 + \dots + x_N\) and at time \(N t\), an exact solution. The period \(2\pi\) is fixed and cannot be passed as L. The linear parts of the problem will be discretized using mpi4py-fft [1]. For time-stepping, the problem will be solved fully-implicitly, i.e., the nonlinear system containing the full right-hand side is solved by a Newton-Krylov method [2].

Parameters:

  • lintol (float, optional) – Absolute tolerance for the SciPy Newton-Krylov solver, passed as x_tol, i.e., applied to the maximum norm of the Newton step. SciPy additionally requires the maximum norm of the residual to be below its default f_tol of about 6e-6.

  • liniter (int, optional) – Maximum number of Newton iterations of the Newton-Krylov solver, passed as maxiter. If the solver does not converge, the last iterate is used without a warning.

  • **kwargs – Passed on to nonlinearschroedinger_imex, see there: c, nvars, spectral and comm. useGPU has to be False.

References

[1]

Lisandro Dalcin, Mikael Mortensen, David E. Keyes. Fast parallel multidimensional FFT using advanced MPI. Journal of Parallel and Distributed Computing (2019).

[2]

https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.newton_krylov.html

class nonlinearschroedinger_imex(c=1.0, **kwargs)[source]¶

Bases: IMEX_Laplacian_MPIFFT

Periodic nonlinear Schrödinger equation with mpi4py-fft, IMEX with the Laplacian implicit, nonlinearity explicit.

Example implementing the \(N\)-dimensional nonlinear Schrödinger equation with periodic boundary conditions

\[\frac{\partial u}{\partial t} = i \Delta u + 2 N c i |u|^2 u\]

for fixed parameter \(c \in \{0, 1\}\) and \(N=2, 3\), on \([0, 2\pi]^N\). The factor \(N\) makes the one-dimensional breather solution (39) of https://doi.org/10.1007/BF01017105, taken along \(x_1 + \dots + x_N\) and at time \(N t\), an exact solution. The period \(2\pi\) is fixed and cannot be passed as L. The linear parts of the problem will be solved using mpi4py-fft [3]. Semi-explicit time-stepping is used here to solve the problem in the temporal dimension, i.e., the Laplacian will be handled implicitly.

Parameters:

  • nvars (tuple, optional) – Spatial resolution

  • spectral (bool, optional) – If True, the solution is computed in spectral space.

  • c (float, optional) – Nonlinearity parameter, either 0 or 1.

  • comm (MPI.COMM_World) – Communicator for parallelisation.
