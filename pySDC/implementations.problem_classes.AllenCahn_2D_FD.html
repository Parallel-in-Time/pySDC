implementations.problem_classes.AllenCahn_2D_FD module¶

class allencahn_fullyimplicit(nvars=(128, 128), nu=2, eps=0.04, newton_maxiter=200, newton_tol=1e-12, lin_tol=1e-08, lin_maxiter=100, inexact_linear_ratio=None, radius=0.25, order=2, useGPU=False)[source]¶

Bases: Problem

Example implementing the two-dimensional Allen-Cahn equation with periodic boundary conditions, with the two phases at \(u = 0\) and \(u = 1\)

\[\frac{\partial u}{\partial t} = \Delta u + \frac{1}{2\varepsilon^2} (2u - 1)\left(1 - (2u - 1)^\nu\right)\]

for a constant \(\nu\), which at the default \(\nu = 2\) is the usual \(\Delta u - \frac{2}{\varepsilon^2} u (1 - u)(1 - 2u)\).

Initial condition are circles of the form

\[u({\bf x}, 0) = \frac{1}{2}\left(1 + \tanh\left(\frac{r - \sqrt{x_i^2 + y_j^2}} {\sqrt{2}\varepsilon}\right)\right)\]

for \(i, j=0,..,N-1\), where \(N\) is the number of spatial grid points. For time-stepping, the problem is treated fully-implicitly, i.e., the nonlinear system is solved by Newton.

Parameters:

  • nvars (tuple of int, optional) – Number of unknowns in the problem, e.g. nvars=(128, 128).

  • nu (int, optional) – Exponent of the double well; \(\nu = 2\) is the standard Allen-Cahn nonlinearity.

  • eps (float, optional) – Scaling parameter \(\varepsilon\).

  • newton_maxiter (int, optional) – Maximum number of iterations for the Newton solver.

  • newton_tol (float, optional) – Tolerance for Newton’s method to terminate.

  • lin_tol (float, optional) – Tolerance for linear solver to terminate.

  • lin_maxiter (int, optional) – Maximum number of iterations for the linear solver.

  • radius (float, optional) – Radius of the circles.

  • order (int, optional) – Order of the finite difference matrix.

  • useGPU (bool, optional) – Run on the GPU with CuPy instead of on the CPU with NumPy.

reaction(u)[source]¶

The reaction term, \(\frac{1}{2\varepsilon^2}(2u - 1)\left(1 - (2u - 1)^\nu\right)\).

The wells sit at \(u = 0\) and \(u = 1\), so the double well is symmetric about \(2u - 1\); writing the term in that variable is what lets \(\nu\) keep the meaning it has always had here. For the default \(\nu = 2\) this is \(-\frac{2}{\varepsilon^2} u (1 - u)(1 - 2u)\).

reaction_cubic(u)[source]¶

The stiff part of reaction(), \(-\frac{1}{2\varepsilon^2}(2u - 1)^{\nu + 1}\).

reaction_cubic_prime(u)[source]¶

Derivative of reaction_cubic().

reaction_linear(u)[source]¶

The rest of reaction(), \(\frac{1}{2\varepsilon^2}(2u - 1)\), so the two sum back to it.

reaction_prime(u)[source]¶

Derivative of reaction(), ready to go on the diagonal of a Jacobian.

This class implements the two-dimensional Allen-Cahn (AC) equation with periodic boundary conditions, with the two phases at \(u = 0\) and \(u = 1\)

\[\frac{\partial u}{\partial t} = \Delta u + \frac{1}{2\varepsilon^2} (2u - 1)\left(1 - (2u - 1)^\nu\right)\]

for a constant \(\nu\), which at the default \(\nu = 2\) is the usual \(\Delta u - \frac{2}{\varepsilon^2} u (1 - u)(1 - 2u)\).

The initial condition has the form of circles

\[u({\bf x}, 0) = \frac{1}{2}\left(1 + \tanh\left(\frac{r - \sqrt{x_i^2 + y_j^2}} {\sqrt{2}\varepsilon}\right)\right)\]

for \(i, j=0,..,N-1\), where \(N\) is the number of spatial grid points. For time-stepping, a special AC-splitting is used here to get another kind of semi-implicit treatment of the problem: The term \(\Delta u - \frac{1}{2\varepsilon^2}(2u - 1)^3\) is handled implicitly and the nonlinear system including this part will be solved by Newton. \(\frac{1}{2\varepsilon^2}(2u - 1)\) is solved by a linear solver provided by a SciPy routine.
