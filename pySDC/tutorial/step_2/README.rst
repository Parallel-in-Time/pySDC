Step-2: Data structures and my first sweeper
============================================

In this step, we will dig a bit deeper into the data structures of ``pySDC`` and work with our first SDC sweeper.

- **Part A: Step data structure.** The description dictionary, and the step, level and problem it creates.
- **Part B: My first sweeper.** One IMEX SDC step, done by hand with the sweeper's routines.
- **Part C: Using pySDC's frontend.** The same with a controller, which is how pySDC is normally used.

Each part is a Python script in `jupytext <https://jupytext.readthedocs.io>`_ "percent" format: run it with
``python``, open it as a notebook in Jupyter, or read it on the website, where it is executed with every build.
