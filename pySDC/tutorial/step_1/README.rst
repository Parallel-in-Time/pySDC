Step-1: A first spatial problem
===============================

In this step, we create a spatial problem and play with it a little bit.
No SDC, no multi-level here so far.

- **Part A: Spatial problem setup.** A first problem class, its data types, and a test of its operator.
- **Part B: Spatial accuracy check.** Measuring the order of accuracy in space.
- **Part C: Collocation problem setup.** Nodes, the collocation matrix, and the collocation problem solved directly.
- **Part D: Collocation accuracy check.** Measuring the order of accuracy in time.

Each part is a Python script in `jupytext <https://jupytext.readthedocs.io>`_ "percent" format: run it with
``python``, open it as a notebook in Jupyter, or read it on the website, where it is executed with every build.
