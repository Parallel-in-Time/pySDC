copy(*args, **kwargs)[source]¶

Copy the mesh, keeping its type.

CuPy’s ndarray is a Cython extension type whose copy returns the base class rather than type(self), unlike NumPy’s. Without this, a copy of a mesh silently stops being one and loses the components along with the __abs__ that does the MPI reduction.

Returns:

copy of the mesh, of the same type

mesh
